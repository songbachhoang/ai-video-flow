What the job required

Nine things you only learn by shipping

Each of these is a competency the role names. Here's what I hit, and the concrete takeaway.

1

Prompting

A two-line grammar: a plain-English intent line, then an ordered tag line — shot → subject → motion → camera → light → DOF → style → res. Front-loading shot type + subject stops the model drifting.

Takeaway: realism is a prompt skill. “cinematic / dusk / 8k / bokeh” reads fake; “documentary, natural golden-hour light, real architecture, 35mm, film grain, no bloom” fixed it.

2

Cost & unit economics

Preflighted real cost before spending (get_cost): one 8s Fast clip = 28 credits = $2.10. My plan's estimate ($0.45–0.55) was off by ~4–5×.

Takeaway: quote cost-per-usable and yield, never vibes. Measure, then the budget cap (3 re-rolls/shot) becomes a real stop-loss, not a slogan.

3

Credit ops

Tiers gate the model: Starter = Fast only, 720p, 2 concurrent jobs; Plus unlocks std + 1080p + 6 concurrent. Credits don't roll over; no à-la-carte packs.

Takeaway: the billing API even hid the Starter tier — verify pricing against the real UI. Tooling can mislead; concurrency limits shape your batch strategy.

4

Identity & consistency

One original character, reused across every shot = the catalog anchor. Learned the trap: a trained “Soul” only drives Soul models — for Seedance you use reference Elements / image refs.

Takeaway: consistency is won in the reference pack, not the prompt. Same face + same kit across 4 shots, zero drift.

5

Script & story

B-roll ≠ an ad. Wrote a 4-beat arc — ritual → departure → the city gathers → pride — in sport-brand register, each VO line mapped to a beat.

Takeaway: the “city gathers” beat is the emotional engine. Story is what makes a viewer believe, and share.

6

Voice

Voiceover narration (not on-camera dialogue) sidesteps lip-sync. Cut a UK-voice VO for timing and emotion.

Takeaway: demo with free TTS; for final, swap a premium voice or human — the voice is half the believability.

7

Process / the system

An 8-stage pipeline with one QA gate (5-dimension rubric) + a decision tree, all version-controlled: pipeline.md, prompts.md, qa-log.csv, and a one-command /make-campaign.

Takeaway: UI for taste, code for scale. Winning prompts/refs get promoted to a template library — the loop compounds.

8

The virality test

Ran a virality predictor and, more usefully, diagnosed why: open on the face in the first 0.5s, earn retention with a payoff beat, and a fake-looking background caps shares.

Takeaway: “viral” is engineered — hook + payoff + perceived quality + native audio, not luck.

9

Responsible ownership

Declined to generate a real celebrity's likeness — even on request — on rights/consent grounds. Original characters only; branding handled deliberately; never auto-publish to a live channel.

Takeaway: owning the pipeline means owning the guardrails. That's a feature you can show, not a limitation.

The single biggest craft lesson

“The background looks fake” — and the prompt fix

Same model, same kit. The only change was the prompt: trading stylized-cinematic cues for grounded documentary ones. That one move is the difference between “obviously AI” and “could be a real shoot.”

✗ Before — “cinematic, dusk, bokeh”

Floodlight bloom + blurred crowd = the tell-tale CG look. Low share-intent.

✓ After — “documentary, golden hour, real architecture”

Real concrete-and-steel facade, natural light, real passers-by. Reads like a photograph.

Reading the result honestly

What I'd fix before betting on it going viral

A workflow owner ships and grades their own output. Here's the honest gap between “good demo” and “believable ad.”

  • Voice: the demo VO is text-to-speech — serviceable, but a premium/human read would lift believability the most.
  • Music: no score yet; a swelling bed does half the emotional work — added at publish with licensed/native-trending audio.
  • Resolution: 720p Fast is the quality + fine-garment-detail ceiling; std/1080p would sharpen the kit's micro-pattern.
  • Hook: for short-form, recut to open on the face in frame one and time the cuts to the track's beat.
